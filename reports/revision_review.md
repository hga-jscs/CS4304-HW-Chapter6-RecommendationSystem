# 第二轮修改意见与验收口径

本轮对照用户给出的量化目标：KKBox Public/Private 均至少 0.705；Synerise churn 至少 0.750、category/SKU 官方加权分数均至少 0.815。它们是实验目标，不能根据方法名称预先认定已经达到。

## 补充交代的问题

上一轮报告了训练内 SVD 的抽样退化，但没有充分突出设计限制：训练样本参与图构建，验证及测试交互没有参与，重构特征的分布可能因此不同。这个结果只能否定当时那一版配置，不能据此否定全局转导图或协同表示。本轮明确增加全 train/test **无标签**图作为单独对照。

原实验记录保留了偏好模型随机验证上涨而平台下降、行序与容量组合未超过旧最佳的结果。本轮会同时列出采用的假设、没有验证的范围、负面结果以及未达标项，补足此前对方法限制的说明。

## 逐项执行与修正

| 意见 | 本轮处理 |
| --- | --- |
| 全 train/test 转导类别、频次、场景与图 | 新增显式模式；读取交互列时不加载 `target`。训练、验证和测试共享一次拟合的无标签状态。它减少统计覆盖和图中是否有该交互造成的错位，不保证消除真实时间漂移。 |
| 全局行号六特征 | 实现位置、前后间隔、累计/剩余次数、末段歌曲热度比。按原文件顺序对齐全量 train/test；行距不是秒数，也不能证明会话或隔天回访。前后统计属于批量转导，不是实时因果特征。 |
| OOF 目标编码 | 实现五项平滑编码。随机验证使用五折折外编码；行序训练使用严格前序块，第一块先验固定 0.5，不能使用未来标签均值。外部验证/测试只查询对应训练标签的统计。 |
| 所有特征默认开启、取消留一、放大树、不重训 | 提供实验配置并逐项消融。转导计数在各阶段采用同一完整统计；旧训练内模式保留留一选项。上轮负面结果不足以支持直接将全部开关改成默认。 |
| 伪未来多任务预训练 | 新增历史内 14 日伪目标窗口、残差 MLP 与 GRU、256 维瓶颈和 201 维头输出。类别词表只由伪输入选择，验证用户的标签不进入训练损失、标准化统计或类别权重。官方 `target/` 不参与构建。 |
| Top-K、价格顺序、购买间隔、标准化 | 上轮增强版已实现这些方向，本轮进一步加入十档价格桶、近 30 日价格桶索引和、紧凑统计块。价格桶不是真实货币金额；平均购买间隔仍为 `span/(n−1)`，不能改成 `span/(n+1)` 后仍称平均间隔。 |
| PQ 连续表示 | 分别拟合商品名称与搜索的“位置—码字”共现因子并池化。缺少原始 PQ 码本，不能称为恢复了原始语义向量，也不把码字编号作为有序实数。 |
| 用户图 128 维 | 从历史购买/加购类别、高频商品及页面构建衰减稀疏图，提取用户因子并按行归一化；未知或没有图交互的用户为零。 |
| 1001 维与长尾桶 | `457+256+96+64+128=1001`。原清单未把 SKU/category 两组 64 桶计入总和；主方案保持 1001 维，额外长尾模式为 1129 维。 |
| 标准化保证均值 0、标准差 1 | 非恒定列在裁剪/量化前按总体均值和方差标准化；裁剪、常量列以及 `float16` 量化后不保证精确为 0/1。 |
| 放开官方仓库修改与统一历史版本号 | 上轮已有 `--allow-modified-official` 调试开关。正式性能比较仍保持官方源码与协议；构建和官方评测使用不同环境时记录各自真实版本，不重写历史记录来制造一致。 |

方法依据延续[上轮核验](feedback_review.md)：[原作者行序说明](https://web-ainf.aau.at/pub/jannach/files/Workshop_WSDMCUP_2018.pdf)、[冠军转导图实现](https://github.com/lystdo/Codes-for-WSDM-CUP-Music-Rec-1st-place-solution/blob/master/input/training/script/svd_process.py)、[Synerise 列编码](https://github.com/Synerise/recsys2025#column-encoding)。

## 验收

基本任务先比较同一末尾 500,000 条记录的相同行序留出，再对候选做全量训练和真实平台评分。无标签全图仍涉及约 993 万行，使用已授权的免费 Kaggle CPU，并记录实际峰值内存。固定一组验证和种子的结果不等于“稳定正向提升”。

拓展任务先核验伪时间窗和目标隔离，训练后生成一套覆盖完整用户的表征，通过原官方格式检查和三项固定下游训练。三个分数同时报告，不把不同表征的单项最优拼成一套成绩；新结果不能替换或改写旧记录。
