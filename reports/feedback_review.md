# 代码评审意见核验

核验日期：2026-11-17。依据为两份用户提供的评审、当前源码、本机包元数据及下列一手资料。本文件评估建议的合理性；是否已实现、实际得分和耗时以对应实验记录为准。

## 处理结论

| 建议或断言 | 结论 | 处理依据 |
| --- | --- | --- |
| 输出目录非空即退出、残留临时文件阻断重试 | 采纳 | 增加明确的覆盖选项，只替换当前实验的已知产物；保留无关文件。解压复用应识别已完成结果，不能仅凭文件非空判断。 |
| 每轮训练、推理重复计算原始数据哈希 | 采纳 | 常规实验可用大小和修改时间记录数据状态；下载完整性与最终提交文件摘要仍有用途。运行时间收益须实测。 |
| 日期整数转成 `float32` | 采纳 | 实测 `20170103` 与 `20170104` 均变成 `20170104.0`。转换为连续天数可以避免日期合并；跨月数值距离本身不等于树模型错误。 |
| ISRC 年份还原 | 采纳，但修正语义 | 两位年表示赋码参考年，不是真实发行年。2017 年世纪切分是历史数据的解释假设，应使用参考年份命名。[IFPI 说明](https://isrc.ifpi.org/isrc-standard/isrc-structure) |
| 绝对频次使全量重训的旧树阈值失效 | 不支持该原因 | 当前重训重新学习树和阈值，并未复用验证模型。频次除以样本数在一次拟合内属于单调缩放；归一化可比较，但不是这项所谓错误的修复。 |
| 无标签场景统计必须删除留一扣减 | 作为实验 | 留一扣减可减少训练样本对自身统计的贡献。训练独立统计与包含测试输入的转导统计适用条件不同，不能只因未使用标签就判定该逻辑无效。 |
| 行序留出与尾段抽样 | 采纳为验证选项 | 参赛原作者明确报告数据按时间排序，并采用尾段验证。应称为有文献依据的行序时间代理；行号差不是实际秒数，也不能直接证明会话边界。[原作者论文，§2.3.2、§3.2](https://web-ainf.aau.at/pub/jannach/files/Workshop_WSDMCUP_2018.pdf) |
| 废弃全量重训，直接用验证模型提交 | 作为实验 | 不重训可节省算力，全量重训则利用更多有标签记录。提供选项并保存与模型匹配的特征状态，不预设哪一种成绩更高。 |
| 用户偏好、行序前后统计、SVD、增大树容量 | 作为实验 | 有竞赛实践依据，但需要分组比较。前后统计使用未来无标签输入时属于批量转导设置；SVD 重构内积须包含奇异值。[冠军时间特征](https://github.com/lystdo/Codes-for-WSDM-CUP-Music-Rec-1st-place-solution/blob/master/input/training/script/timestamp_process.py)、[SVD 实现](https://github.com/lystdo/Codes-for-WSDM-CUP-Music-Rec-1st-place-solution/blob/master/input/training/script/svd_process.py) |
| 拓展任务增加 Top-K 精确偏好、价格和行为统计 | 采纳为优先实验 | 少量哈希桶确有碰撞。Top-K 应仅从历史输入选择；价格是分位桶，桶值求和不能称实际消费金额。平均事件间隔在事件数至少为 2 时应为跨度除以事件数减一。[官方列编码](https://github.com/Synerise/recsys2025#column-encoding) |
| 列标准化、PQ 聚合和增加维度 | 作为实验 | PQ 是离散量化码，不能把编号距离当语义距离。2048 是维度上限，使用更多维度不自动提高质量。官方模型已有 LayerNorm，标准化的额外收益仍须测量。[官方模型](https://github.com/Synerise/recsys2025/blob/e91c1a62f84611151a399ce157e6031a4a73618f/training_pipeline/model.py) |
| 允许修改官方评测源码进行调试 | 采纳显式调试选项 | 记录实际版本、修改状态及结果是否可比；正式对照继续固定官方模型、训练参数和指标。 |
| 所列包版本不存在、环境记录可能伪造 | 不支持 | 本机包元数据与官方 PyPI 一致，且构建环境与官方训练环境本来就是分开的，详见下表。 |
| 固定增加 0.01–0.05 分、全部增强只需 2–3 分钟 | 不支持 | 没有本项目的实测证据。640 维的百万用户 `float32` 累加矩阵已需约 2.56 GB，标准化中间数组和 SVD 工作区还会增加开销。 |

已有说明中“不能利用未知行序”的保守判断可据上述原作者证据更新为“使用有文献依据的行序代理，并通过留出实验验证”。这不等于取得了原始时间戳。冠军的[前后邻居实现](https://github.com/lystdo/Codes-for-WSDM-CUP-Music-Rec-1st-place-solution/blob/master/input/training/script/before_after_process.py)也明确联合训练与测试输入，不能把这种实验表述为仅使用实时可见历史。

## 本轮优先顺序

1. 简化实验覆盖、重试、数据复用与元数据记录，保留结果格式、用户对齐和目标隔离检查。
2. 修正日期表示和 ISRC 命名，独立比较统计方式、行序验证及是否全量重训。
3. 对拓展任务先比较标准化，再比较历史 Top-K、价格桶、活跃度和行为比率组成的增强表征。
4. PQ、SVD 与行序前后特征根据成本和已有结果再推进；不把未完成的实现或未经测量的收益写成结论。通用已有方法应注明来源，项目自己的组合与消融分析才是本项目的具体贡献。
